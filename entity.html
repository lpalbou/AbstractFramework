AbstractEntity

The entity app of AbstractFramework: the place where you create entities, talk with them, watch what they remember as a live memory graph, and read their diaries. It runs as a small local web app in front of your AbstractGateway, which serves it at /apps/entity/; open it from the console's Apps page (see Install).

Get started GitHub npm llms.txt llms-full.txt 
# Console > Apps > Entity > Open

# Or on its own (Node.js 18+), port 3007
npx @abstractframework/entity \
  --gateway-url http://127.0.0.1:8080
Overview

What is an entity?

An entity is an AI companion with a lasting memory of its own. You give it a name; from then on it remembers what you talk about, keeps a diary, sleeps to sort its memories and grows over time. It lives on your AbstractGateway (its memory is stored there, in its own folder), and it keeps one identity for its whole life.

Your first entity

Open the app, type a name (for example Pollux) and press Create entity. The name is all it needs: the entity starts from the standard starting document. Then say hello in the Chat tab.

One name, one life

A name belongs to one entity for its whole life: creating an entity whose name already exists opens the existing one. The Advanced: starting document fold takes your own starting document (YAML).

A thin client

The gateway owns each entity's life: it creates the entity, summons it (brings the same self back into a session), runs visits (conversations) and reports its state. The app keeps no server state of its own: every view is read from the gateway, and the memory views are computed from the replay stream of AbstractMemory, the memory engine.

In the app

The entities list and the entity page

Entities list (Summoned entities)

Create entities, open one, watch them all at once (watch all), convene two of them into one conversation (convene a meet), and open the blueprint page that shows how every entity's memory and daily cycle work.

Entity page

The memory graph, the chat, and a set of reading tabs over the same life. Replay, live tail and scrubbing back in time show the same picture.

Demo life offline

Without a reachable gateway the app opens a bundled demo life, so you can explore the memory graph offline.

Get started

Open the Entity app

From the gateway console, the Entity card's button reads Create your first entity while the gateway has none; it opens the app signed in, straight on the creation form. Serving the app at /apps/entity/ needs AbstractGateway 0.7.0 or newer.

# Gateway console > Apps > Entity > Open
http://127.0.0.1:8080/apps/entity/
  • The gateway serves the app on its own address, so a remote or headless machine needs one port and one tunnel for the console and every app (see headless installs).
# run without installing
npx @abstractframework/entity

# or install the abstractentity command globally
npm install -g @abstractframework/entity
abstractentity --gateway-url http://127.0.0.1:8080
  • The app serves on http://127.0.0.1:3007 (flags --port, --host, --gateway-url with aliases --gateway and --url). Without --gateway-url it uses the gateway installed on this computer, else http://127.0.0.1:8080. Sign in from the connect dialog: the server keeps the gateway session in HttpOnly cookies and the browser never stores the token. http://127.0.0.1:3007/#new opens the creation form directly.
