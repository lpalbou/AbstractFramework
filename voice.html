AbstractVoice

Voice input and output for AI applications: text-to-speech, speech-to-text and optional voice cloning behind one Python API. The base install talks to OpenAI or any OpenAI-compatible audio server; local engines such as Supertonic, Piper, Qwen3-TTS, OmniVoice and Whisper come with explicit extras. Use it as a library, or install it next to AbstractCore and it becomes llm.voice and llm.audio.

GitHub PyPI Documentation llms.txt llms-full.txt 
# Remote OpenAI audio (reads OPENAI_API_KEY)
pip install abstractvoice

# Local text-to-speech + speech-to-text on CPU
pip install "abstractvoice[supertonic,stt]"

# Full local stack: Apple Silicon or GPU
pip install "abstractvoice[apple]"
pip install "abstractvoice[gpu]"
Overview

One voice API, remote or local

You pick a provider (the engine), a model and a voice. The same calls work whether the audio comes from a hosted endpoint or from an engine running in your process.

Remote by default

pip install abstractvoice is light: it installs no PyTorch and no local model. VoiceManager() uses OpenAI audio with OPENAI_API_KEY; the openai-compatible provider points the same calls at any compatible /v1 audio server.

Local engines, when you ask for them

Each local engine sits behind its own extra, and [apple] / [gpu] install the local stack in one go. The interactive abstractvoice command (a spoken chat in the terminal) never downloads a model on its own: you fetch weights with abstractvoice-prefetch. In the library, VoiceManager(allow_downloads=False) gives the same guarantee.

It says what it can do

engine_runtime_status(engine) tells you whether an engine can run here, what is missing, and the install command, without importing the engine. Voice listings name each unavailable provider with a code (runtime_missing, model_not_downloaded, not_configured) and a reason.

Included in the one-line installer. The AbstractFramework installer adds abstractvoice[supertonic,stt] to the gateway: Supertonic text-to-speech and Whisper speech-to-text, both on CPU. This is skipped on musl Linux and on macOS before 13, where no wheels exist; Windows ARM64 gets Supertonic only. The abstractvoice and abstractvoice-prefetch commands are on your PATH (~/.local/bin), and the gateway consoles use the same engine status to show a missing voice engine with its install command. To upgrade, re-run the same install line (on a Mac without Terminal, double-click Install AbstractFramework.command again), see Upgrade; on an installer install, the console’s update runs the installer.

Engines

What runs where

Every engine below is a provider id you can pass to VoiceManager, the CLI or AbstractCore. Only the two remote providers work with the base install; each local engine needs the extra shown. Model weights are licensed separately from AbstractVoice (MIT): check the source of each model you download.

Headless or played aloud

speak() plays through your speakers; speak_to_bytes(), speak_to_file() and speak_to_audio_chunks() return audio for servers and pipelines.

LLM text in, speech out

open_tts_text_stream() takes text as it arrives from a model, cuts it into short segments and starts speaking before the reply is complete.

Microphone and barge-in

Optional microphone listening with voice activity detection, a stop phrase, and acoustic echo cancellation ([aec], Python 3.11+).

Getting started

First words in a few minutes

Requires Python 3.9 or later; several local engines need 3.10+.

Command line

# One-shot: write a WAV with hosted OpenAI audio and exit
OPENAI_API_KEY=... abstractvoice --provider openai --model tts-1 --voice alloy \
  --prompt "Hello from AbstractVoice." --output hello.wav

# Local: fetch the weights once, then chat without the network.
# The AbstractFramework installer already put these commands on PATH; otherwise:
pip install "abstractvoice[supertonic,stt]"
abstractvoice-prefetch --supertonic
abstractvoice-prefetch --stt small
abstractvoice --tts-engine supertonic --stt-engine faster_whisper

# Browser example (needs abstractvoice[web])
abstractvoice web --port 5000

Python

In Python, VoiceManager takes a text-to-speech, a speech-to-text and a cloning engine (for example Supertonic, faster-whisper and OmniVoice with abstractvoice[supertonic,stt,omnivoice]) and offers speak, speak_to_bytes, transcribe_file and clone_voice. The verified AbstractCore call is in the examples below.

Streaming, availability and AbstractCore

# Speak an LLM reply while it is still being generated
stream = vm.open_tts_text_stream()
for delta in llm_text_deltas:   # text chunks from your model
    stream.push(delta)
stream.close()     # no more text
stream.join()      # wait until the last segment is synthesized
# stream.cancel() stops early

from abstractvoice.engine_runtime import engine_runtime_status

# Checks installed packages only: nothing is imported or loaded
status = engine_runtime_status("qwen3-tts")
print(status.installed)        # False when torch/transformers are missing
print(status.reason)           # plain-words explanation
print(status.install_command)  # the pip command for the qwen3-tts extra
from abstractcore import create_llm

llm = create_llm("mlx", model="mlx-community/Qwen3.5-4B-4bit")

speech = llm.generate(
    text="AbstractFramework: write once, generate everything, run anywhere.",
    output={"modality": "voice", "provider": "supertonic", "model": "supertonic-3"},
)
open("tagline.wav", "wb").write(speech.outputs["voice"][0].data)
