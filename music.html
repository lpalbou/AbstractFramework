AbstractMusic

Text-to-music and text-to-audio behind one Python API. The base install is light and calls a remote API (ACE Music by default, or ElevenLabs Music); local models such as ACE-Step XL Turbo and Stable Audio 3 come with explicit extras. Installed next to AbstractCore, it becomes llm.music.

GitHub PyPI Documentation llms.txt llms-full.txt 
# Remote generation (ACE Music)
pip install abstractmusic
export ACEMUSIC_API_KEY=...
abstractmusic t2m "ambient lo-fi study music" \
  --out out.wav --duration 30

# Local ACE-Step
pip install "abstractmusic[acestep]"
Overview

A prompt in, audio out

A thin MusicManager sits over a backend object. You keep the same calls when you move from a hosted API to a model running on your machine.

Light, remote-capable base

pip install abstractmusic installs no Torch, Diffusers, Transformers or NumPy. It includes stdlib-only clients for ACE Music and ElevenLabs Music. Output is WAV by default; ACE Music can also return MP3 or FLAC.

Local models, when you ask

Each local runtime is an extra, with [apple] / [gpu] profiles. Weights come from the Hugging Face cache. On Apple Silicon, ACE-Step tries MPS bfloat16, then MPS float32, and uses CPU float32 only as a last resort.

Text planning

A dependency-free planner can enrich a short prompt, add BPM or key hints and write template lyrics (--enhance-prompt, --auto-lyrics). A host can plug in its own planner, for example an LLM through AbstractCore.

Included in the one-line installer. The AbstractFramework installer installs AbstractMusic with the gateway: the remote backends on every profile, plus the local model runtimes with the apple and gpu profiles. The abstractmusic command is on your PATH (~/.local/bin). To upgrade, re-run the same install line (on a Mac without Terminal, install the latest .pkg again), or use Update on the Gateway card of the console (terminal console: F3) or in the menu-bar icon: see Upgrade.

Backends

Remote and local backends

AbstractMusic itself is MIT. Each backend has its own terms: check the provider or model license before commercial use.

BackendRunsInstallModel and terms
acemusic (default)RemotebaseACE Music hosted API; needs ACEMUSIC_API_KEY. Text-to-music with optional lyrics; WAV, MP3 or FLAC. Output rights follow the provider's terms.
elevenlabsRemotebaseElevenLabs Music only (voice belongs in AbstractVoice); needs ELEVENLABS_API_KEY and may need a paid Music-enabled plan. Accepts composition plans.
acestepLocal[acestep]ACE-Step/acestep-v15-xl-turbo-diffusers, MIT, 8 steps: the validated default. The XL SFT and XL base checkpoints run at about 50 steps.
stable-audio-3Local[stable-audio-3]stabilityai/stable-audio-3-small-music, up to 120 s, 44.1 kHz stereo. Gated; Stability AI Community License. Passed 30 s and 120 s validation runs, not yet recommended pending broader and GPU validation. Also Small SFX and the GPU-oriented Medium (up to 380 s).
stable-audioLocal[stable-audio]stabilityai/stable-audio-open-small, clips up to 11 s, suited to short sounds. Gated; Stability AI Community License.
musicgenLocal[musicgen]facebook/musicgen-small. Weights are CC BY-NC 4.0: non-commercial validation only.

Lyrics and style tags

Pass lyrics (or lyrics="auto"), [Instrumental], and provider-neutral positive_styles / negative_styles for instruments, vocals and mix.

Long pieces

From 45 seconds on, a compact intro/build/bridge/climax/outro section map is added to the prompt by default; --no-structure-prompt turns it off.

Provider discovery

The AbstractCore plugin lists only providers that can run now, without loading weights; provider_details() says why the others cannot (missing key, extra or download).

Getting started

Your first track

Requires Python 3.10 or later. With the AbstractFramework installer, the abstractmusic command is already on your PATH; otherwise pip install abstractmusic (plus the extra of each local backend).

Command line

# ElevenLabs Music
abstractmusic --backend elevenlabs t2m "cinematic instrumental synth cue" \
  --format mp3 --out out.mp3 --duration 30

# Local ACE-Step, with prompt enhancement and template lyrics
abstractmusic --backend acestep t2m "heroic fantasy epic music" \
  --enhance-prompt --auto-lyrics --print-plan --out out.wav --duration 30

# Local Stable Audio 3 (accept the model terms on Hugging Face first)
abstractmusic --backend stable-audio-3 t2m "rhythmic space shooter game music" \
  --out out.wav --duration 30 --steps 16

# Interactive REPL: /engines, /models, /engine, /duration, /run ...
abstractmusic repl
from abstractmusic import MusicManager
from abstractmusic.backends import AceMusicBackend, AceMusicBackendConfig

backend = AceMusicBackend(config=AceMusicBackendConfig(api_key="..."))
mm = MusicManager(backend=backend)

wav_bytes = mm.t2m("uplifting synthwave with punchy drums", duration_s=30.0)
open("out.wav", "wb").write(wav_bytes)
# pip install "abstractmusic[acestep]"
from abstractmusic import MusicManager
from abstractmusic.backends import AceStepBackend, AceStepBackendConfig

mm = MusicManager(backend=AceStepBackend(config=AceStepBackendConfig()))

wav_bytes = mm.t2m(
    "smooth jazz trio, brushed drums, warm upright bass",
    duration_s=20.0,
    lyrics="[Instrumental]",
    seed=42,
)
open("jazz.wav", "wb").write(wav_bytes)
# pip install abstractcore abstractmusic  (the plugin is discovered automatically)
from abstractcore import create_llm

llm = create_llm(
    "ollama", model="qwen3:4b-instruct",   # any provider; the LLM does not make the audio
    music_backend="acemusic",
    music_acemusic_api_key="...",
)
wav_bytes = llm.music.t2m("ambient lo-fi study music", format="wav", duration_s=10.0)

# Which providers can run here, and why the others cannot
details = llm.music.provider_details(task="text_to_music")
