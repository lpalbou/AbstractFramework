Your first hour

Install, try it, make it yours

Install with the right profile 15 min

The installer picks the profile for your machine: apple on an Apple Silicon Mac with macOS 14+, which brings the local MLX engines for images and video; gpu on Linux with an NVIDIA or AMD GPU; light elsewhere, where generation goes through a service. Every profile includes local voice (Supertonic text-to-speech and Whisper speech-to-text, on the processor).

curl -LsSf https://raw.githubusercontent.com/lpalbou/AbstractFramework/main/scripts/install.sh | sh

Let the console choose models that fit 10 min

In the first-run guide’s Default model step, click Use recommended defaults: it sets text, voice, images and video wherever this computer can run them, and a route it cannot run shows the reason. The Models tab has Voice, Image and Video capability filters, the download size of each build, and a fit badge. Downloads start only when you click Download.

Hear a voice 5 min

Open the console’s Sandbox tab. It shows one output button per configured capability: choose Voice, type a line and send it; the answer comes back as audio. AbstractVoice also clones a voice from a reference recording, with OmniVoice, F5-TTS or Chroma locally or with an OpenAI-compatible service.

Compose a track 5 min

Music is not set by Use recommended defaults. In the console’s Multimodal tab, set the music route to ACE Music (a service; set ACEMUSIC_API_KEY) or to ACE-Step 1.5 XL turbo, which runs locally on an Apple Silicon Mac from 18 GB or on an NVIDIA GPU (which machine runs what). Then choose Music in the Sandbox and describe the track. AbstractMusic lists every backend and its licence.

Paint an image 10 min

Choose Image in the Sandbox and describe the picture. From Python, with the same defaults, it is one call. Python code runs in an environment of your own: the one-line installer keeps AbstractCore inside the gateway’s tool environment. On an Apple Silicon Mac, install the pinned framework with its local engines:

pip install "abstractframework[apple]==0.6.1"   # Python 3.12; builds compiled extras, so it needs a C/C++ compiler

The mlx and mlx-gen lines below run only on Apple Silicon. On Linux with an NVIDIA GPU, install "abstractframework[gpu]" and route images to Diffusers; on a light install, use a cloud provider for the text model and the image route (AbstractVision backends).

from abstractcore import create_llm

# The capability routes come from AbstractCore's config (set by the step above,
# or the gateway console's recommended defaults); the text model is explicit.
llm = create_llm("mlx", model="mlx-community/Qwen3.5-4B-4bit")

image = llm.generate("A watercolor illustration of a lighthouse on a rocky coast at dawn, "
                     "soft light, calm sea, seagulls in the distance", output="image")
open("lighthouse.png", "wb").write(image.outputs["image"][0].data)

Edits take a source image (and optional style references) with the same output="image", and video routes take a prompt or a still. See AbstractVision.

Chain them in a workflow 15 min

Open Flow from the console’s Apps page (/apps/flow/) and chain an LLM step that writes a scene, a voice step that narrates it and an image step that paints it. One turn can return text, audio and an image, all stored with the run. Publish it, then launch it from the Observer or with one API call (POST /api/gateway/runs/start), or pick it as a chat’s agent in AbstractCode once it declares abstractcode.agent.v1.

Three things to try

Then make it yours

TRY 1

Your narrator

Clone a voice from a clean recording of your own voice, then have it read your script. A transcript of the reference helps the engines that use one; AbstractVoice fills it in with speech-to-text when it is missing.

Cloning engines

TRY 2

A soundtrack

Generate 15 seconds of music locally with ACE-Step, naming the provider and model in the call (Apple Silicon, in the environment from the image step):

from abstractcore import create_llm

llm = create_llm("mlx", model="mlx-community/Qwen3.5-4B-4bit")

music = llm.generate(
    text="Calm ambient piano with soft strings, warm and hopeful, instrumental",
    output={"modality": "music", "provider": "acestep",
            "model": "ACE-Step/acestep-v15-xl-turbo-diffusers", "duration_s": 15},
)
open("ambient.wav", "wb").write(music.outputs["music"][0].data)

Backends and licences

TRY 3

A short video, then 3D

On an Apple Silicon Mac with 96 GB or more, AbstractCore 2.18.1 (coming) recommends Wan 2.2 TI2V-5B through MLX-Gen as the video route (on 64 GB, set it yourself and generate at 832×480). Ask for "a crystal clear river in the mountains", or animate a still with image-to-video. To turn one object in an image into a GLB model, install Abstract3D (separately) and run TripoSR locally.

Good to know

Worth knowing

Hardware, plainly. Local image and video models need a lot of memory. On NVIDIA with Diffusers, the AbstractVision guide matches GPUs with up to 16 GB of VRAM to SD 1.5 and 24–32 GB to FLUX.2 Klein 4B. For Wan 2.2 video through MLX-Gen, AbstractCore 2.18.1 (coming) gives TI2V-5B about 63.5 GiB at its default 1280×704 size (121 frames) and recommends it from 96 GB; at 832×480 it gives about 34.3 GiB, which a 64 GB Mac can run when you set the video route yourself. The released AbstractCore 2.18.0 catalog records a 58.47 GiB peak at 1280×704 (17 frames) and 25 GB at 832×480. The larger A14B models need more: about 72 GiB at their default 1280×720 size (measured on a 128 GB Mac). Which model fits which Mac. When your machine is too small, the console says so, and a service is the better route.
Licences travel with the model. Each engine keeps its own terms: Supertonic voices, Piper voices and Stable Audio have their own licences, MusicGen is for non-commercial use, and some 3D and audio models are gated. The package pages list them.
Only clone voices you are allowed to use. Voice cloning works from a short reference recording; use your own voice or one you have permission for.
