## Fix-forwards and relocks

- abstractcore `fa77136`: `abstractcore.utils.identity` read its asset through
  `importlib.resources.files` on a package without `__init__.py`, which fails on Python 3.9 (the bug
  was new in 2.16.0 and never shipped); the 5 GGUF prompt-opened tests skip when llama-cpp is absent.
- abstractcore `f1735a1`: one `analyze_code` truncation test skipped on Python < 3.10 (CPython 3.9
  parser segfault, order-dependent, pre-existing; follow-up 0919).
- abstractcore `ffbd1e6` + `1190cf1` (coordinator): complete tool calls left inside a thinking block
  are recovered and executed; changelog (operator ruling in 0918).
- abstractcode `a636806`: test-only; the `/model` MTP-offer scenarios run on their own threads
  (thread-local reactive timers fired into a disposed harness on Linux CI).
- Relocks (0899): abstractcode `b243398` (web: ui-kit 0.1.12, panel-chat 0.1.17), observer
  `bf33805`, entity `16de0a3`, continuum `c2530d1` (app-server 0.1.10). Tags went on the relock
  commits, as STAGING deviation 5 required.
