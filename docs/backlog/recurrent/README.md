# Recurrent backlog tasks

Process passes that run repeatedly, never "complete". They have no numeric ID (they are not work
items) and no board home.

- [`backlog-and-adr-hygiene.md`](backlog-and-adr-hygiene.md): counts, filenames, duplicates, stale
  items, ADR links.
- [`post-completion-follow-up-triage.md`](post-completion-follow-up-triage.md): turn completion-report
  residuals into items, or record why not.
