## The Assistant web app is in no root inventory (operator decision D4)

`@abstractframework/assistant` (AbstractAssistant's `web/`, 0.1.3 on npm, 0.2.0 in its manifest) is
not in `NPM_RELEASE_VERSIONS`, not in the installers' `AF_NPM_APPS` / `$AfNpmApps`, not in the
manifest's `npm_apps`, and `scripts/lib/packages.txt` has no row for it (only the Python
`abstractassistant` row). So the release planner and the workspace scripts do not see it, and the
root records no version for it. The operator decides (D4) whether 0.14.0 lists it. If yes, the cut
adds it to all four places; its `packages.txt` row, from its `package.json`
(`app-server` a dependency, `ui-kit` and `panel-chat` bundled from devDependencies):

```text
assistant-web | abstractassistant | lpalbou/AbstractAssistant | npm | web | npm | @abstractframework/assistant | 2 | app-server:dep,ui-kit:dev,panel-chat:dev
```

and the root row's `deps` gains `assistant-web:app`. If not, it stays outside the root for 0.14.0
and the release report says so. This draft changes neither.
