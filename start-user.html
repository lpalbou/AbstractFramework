Your first hour

Install, try it, make it yours

Install 10–15 min

On a Mac, download AbstractFramework-Installer.pkg and double-click it (the first time, allow it under System Settings > Privacy & Security > Open Anyway). On macOS or Linux you can paste one line instead; Windows has its own line on the install page.

curl -LsSf https://raw.githubusercontent.com/lpalbou/AbstractFramework/main/scripts/install.sh | sh

Press Return when it asks whether to start at login. When it says AbstractFramework is ready., your browser opens the console, already signed in.

Pick an engine and a model 10 min

The first-run guide opens by itself. In Local engines, click Install on Ollama or LM Studio if none is found (on Apple Silicon, MLX is already there). In Default model, click Use recommended defaults, then Download on the recommended model and Use as default when it finishes. The catalog opens on the models that fit this computer.

Prefer a cloud model? Add your key under Providers (OpenAI, Anthropic, OpenRouter, Portkey or any OpenAI-compatible service) instead.

Say hello 5 min

On a Mac, open the Apps step (or the console’s Apps tab) and click Install, then Open, on the Assistant card: it starts in the menu bar, already signed in. On any computer, the console’s Sandbox tab runs a quick chat against your defaults, and AbstractCode in the browser (/apps/code/) keeps longer conversations with files. Prefer a terminal? The installer put abstractcode on your PATH: sign it in once with the abstractcode login --token <token> line from the installer’s summary.

Talk to it 5 min

Every install includes local voice: Supertonic text-to-speech and Whisper speech-to-text, on CPU. In the Assistant, press ⌘⇧V for voice conversation mode: listen, send, speak, listen again. The Assistant captures the microphone itself; speech-to-text and text-to-speech run on the gateway.

Let it work for you 10 min

In an Assistant conversation, click the clock button and choose Schedule this conversation…: every 8 hours, say, with Independent context. The switcher’s Automations tab shows each run as a chat turn, and the menu bar notifies you only when a run needs you. How automations work

Three things to try

Then make it yours

TRY 1

A daily digest

Ask: "Search the web for news about <a topic you follow> and summarise the three most important items with links." Then schedule it every 24 hours with growing context, so each run can say what changed.

TRY 2

Talk hands-free

Open voice mode (⌘⇧V) and ask for a recipe while you cook. Replies are spoken as they stream from the gateway.

Voices and engines

TRY 3

Continue on another device

Start a conversation in the Assistant, then open AbstractCode in the browser: every client reads the same gateway sessions. Turn on Local network in the console’s Network tab to reach it from your phone.

Good to know

Worth knowing

Your data stays on your computer. The gateway listens on 127.0.0.1 only until you choose otherwise, and your chats, runs and settings live in your user folder (~/Library/Application Support/AbstractGateway on macOS, ~/.local/share/abstractgateway on Linux). A cloud provider sees what you send it; a local model does not leave your machine.
Local models need memory. The console recommends a model for each capability from your machine's memory and graphics (the full table). A slow or tight model is better replaced by a smaller one or a cloud provider.
Upgrading. Re-run the same install line (on a Mac without Terminal, install the latest .pkg again), (an Update button that runs the installer is coming with AbstractGateway 0.7.2). Upgrade
The Assistant is a Mac app. macOS is its primary target; on Linux and Windows use the console's Sandbox and the browser apps.
